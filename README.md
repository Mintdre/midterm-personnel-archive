# Personnel Archive - Gladiia [AA05]

A personal archive dashboard for Arknights operator Gladiia, themed with the **Rosé Pine Moon** color palette.

## Project Structure
- `assets/images/`: Contains operator portraits and badge icons.
- `css/`: Contains `styles.css` for site styling.
- `js/`: Contains `script.js` with operator data and display logic.
- `index.html`: Main structure of the archive.

## Features
- Interactive operator profile card.
- Modern dark theme using the Rosé Pine Moon palette.
- Demonstrates usage of modern JavaScript variable declarations (`var`, `let`, `const`).
